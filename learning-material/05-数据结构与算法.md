# 数据结构与算法

数据结构和算法是编程的地基：选对结构，增删改查的时间复杂度相差几个数量级。学习重点：结构特性、时间/空间复杂度、常见算法范式。

## 1. 复杂度

- **大 O 表示法**：描述最坏情况下耗时随输入规模的增长，忽略常数与低阶项。
- 常见量级：O(1) < O(log n) < O(n) < O(n log n) < O(n²) < O(2ⁿ)。
- 空间复杂度同理：额外开辟的内存规模。

## 2. 线性结构

- **数组**：连续内存，按下标 O(1) 访问，插入删除 O(n)（需要搬移）。
- **链表**：节点+指针，插入删除 O(1)（已知位置），随机访问 O(n)。单向/双向/循环。
- **栈**：后进先出（LIFO），函数调用栈、括号匹配、表达式求值。
- **队列**：先进先出（FIFO），任务排队、消息缓冲。循环队列复用空间。

## 3. 树

- **二叉树**：每个节点最多两个孩子；前序/中序/后序遍历、层序遍历（BFS）。
- **二叉搜索树（BST）**：左小右大，查找/插入平均 O(log n)；退化为链则 O(n)。
- **平衡树**：AVL（严格平衡）、红黑树（近似平衡，Java TreeMap/HashMap 冲突链的底层）、B 树/B+ 树（数据库索引）。
- **堆**：完全二叉树，大顶堆/小顶堆，插入/取顶 O(log n)；用于优先队列、TopK、堆排序。
- **Trie 前缀树**：字符串前缀匹配，敏感词过滤、自动补全。

## 4. 图

- 表示：邻接矩阵、邻接表。
- 遍历：深度优先（DFS，栈/递归）、广度优先（BFS，队列，求最短路径）。
- 最短路径：Dijkstra（非负权，贪心）、Floyd（全源）。
- 拓扑排序：任务依赖、课程安排（本项目任务图谱的前置依赖即 DAG 关系）。
- 并查集：快速判断连通性，最小生成树 Kruskal。

## 5. 排序

- **O(n²)**：冒泡、插入（少量数据接近有序时最快）、选择。
- **O(n log n)**：归并（稳定、需额外空间）、快排（原地、工程首选）、堆排序。
- **O(n+k)**：计数、桶、基数（数据范围有限时）。
- 稳定性：相等元素相对顺序不变（归并、插入、冒泡稳定；快排、选择不稳定）。
- 工程实践：快排 + 插入排序混合（数据少时切插入排序），如 JDK 的 Arrays.sort。

## 6. 查找与哈希

- 二分查找：有序数组，O(log n)，注意边界写法（左闭右开）。
- **哈希表**：数组 + 哈希函数，平均 O(1)；冲突用链地址法或开放寻址；负载因子控制扩容。
- 哈希与布隆过滤器：判断"一定不在 / 可能在"，用于缓存穿透防护。

## 7. 经典算法范式

- **双指针**：有序数组去重、快慢指针判环。
- **滑动窗口**：子串/子数组问题，窗口左右边界移动。
- **递归与分治**：拆分子问题求解合并，如归并排序、二分。
- **动态规划（DP）**：重叠子问题 + 最优子结构，状态转移方程；斐波那契、背包、最长公共子序列。
- **贪心**：局部最优推导全局最优，需证明；区间调度、哈夫曼编码。
- **回溯**：试探-撤销，N 皇后、全排列、数独。
- **字符串**：KMP（部分匹配表）、Trie、Rabin-Karp 滚动哈希。

## 8. 刷题建议

1. 按主题刷而不是乱刷：数组→链表→栈队列→树→图→DP。
2. 每道题先想暴力解，再优化复杂度，再写代码。
3. 高频考点：二叉树遍历、链表反转、快慢指针、哈希计数、区间合并、经典 DP。
4. 面试表达：先说思路和复杂度，再动手，边界条件（空、单元素、溢出）提前说明。
