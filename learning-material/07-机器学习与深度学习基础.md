# 机器学习与深度学习基础

机器学习：让程序从数据中学习规律而非显式编程。深度学习：用多层神经网络自动提取特征，是大模型（LLM）的技术底座。

## 1. 机器学习基本概念

- **三要素**：数据、模型（假设空间）、学习算法（优化目标）。
- **监督学习**：有标签。分类（垃圾邮件判断）、回归（房价预测）。
- **无监督学习**：无标签。聚类（K-Means）、降维（PCA）。
- **半监督/自监督**：少量标签 + 大量无标签数据（BERT 的掩码语言模型即自监督）。
- **强化学习**：通过奖励信号学习策略（AlphaGo、RLHF）。

## 2. 核心流程

1. 数据收集与清洗（缺失值、异常值、标准化）
2. 特征工程（选择、变换、编码）
3. 划分训练集/验证集/测试集
4. 训练模型 → 评估 → 调参迭代
5. 部署与监控（数据漂移）

## 3. 常用模型

- **线性回归 / 逻辑回归**：最简单可解释的基线模型。
- **决策树 / 随机森林 / GBDT（XGBoost、LightGBM）**：表格数据的王者，工业界最常用。
- **SVM**：小样本高维分类。
- **KNN**：惰性学习，按距离投票。
- 评估指标：准确率、精确率、召回率、F1（分类）；MSE、MAE（回归）；AUC 综合排序能力。
- 过拟合 vs 欠拟合：过拟合靠正则化（L1/L2）、Dropout、早停、交叉验证；欠拟合靠增强模型能力。

## 4. 深度学习基础

- **神经网络**：输入层 → 隐藏层（加权求和 + 非线性激活）→ 输出层。激活函数：ReLU、Sigmoid、Tanh。
- **反向传播**：链式法则计算梯度，梯度下降更新权重。学习率、动量、Adam 优化器。
- **损失函数**：交叉熵（分类）、均方误差（回归）。
- **卷积网络（CNN）**：卷积核提取局部特征 + 池化降采样，用于图像。
- **循环网络（RNN / LSTM）**：处理序列，长短期记忆缓解梯度消失；已逐步被 Transformer 取代。
- **Transformer**：自注意力（Self-Attention）并行处理序列、全局建模，是大模型的基石。

## 5. Transformer 与大模型

- **自注意力**：Q（查询）、K（键）、V（值）三矩阵，注意力权重 = softmax(Q·Kᵀ/√d)·V，让每个 token 关注所有 token。
- **多头注意力**：多组 Q/K/V 并行，捕捉不同子空间的关系。
- **位置编码**：注入位置信息，弥补并行处理丢失的顺序。
- **编码器-解码器架构**：GPT 只用解码器（自回归生成），BERT 用编码器（双向理解）。
- **训练三阶段**：预训练（海量文本，预测下一个词）→ 指令微调（SFT，对齐人类指令）→ 人类反馈强化学习（RLHF，对齐偏好）。
- **缩放定律**：参数、数据、算力同增，能力涌现（推理、上下文学习）。

## 6. 机器学习工程

- **Embedding 与检索**：句子/文档编码为向量，相似度检索（余弦相似度），RAG 的基础。
- **评估与防幻觉**：检索引用约束、拒答策略比单纯"别编造"有效。
- **算力**：GPU 并行（CUDA），推理优化（量化、蒸馏、缓存）。
- **MLOps**：实验跟踪、模型版本、A/B 测试、监控漂移。

## 7. 学习路径

1. 数学基础：线性代数（矩阵、向量）、概率统计、微积分（梯度）。
2. Python + NumPy/Pandas 处理数据。
3. 经典 ML：sklearn 跑通分类/回归/聚类全流程。
4. 深度学习：PyTorch 搭网络，理解反向传播。
5. Transformer：手写小型注意力，理解大模型原理。
6. 大模型应用：Prompt、RAG、微调（LoRA）、Agent。
