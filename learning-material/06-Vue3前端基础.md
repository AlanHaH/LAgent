# Vue 3 前端基础

Vue 3 是渐进式前端框架：声明式渲染 + 组件化 + 响应式系统。配套 TypeScript、Vite 构建、Pinia 状态管理、Vue Router 路由、Element Plus 组件库。

## 1. 响应式与组合式 API

- **setup / `<script setup>`**：组合式 API 入口，逻辑按功能组织而非选项分块。
- **ref / reactive**：`ref()` 包基本类型（模板中自动解包），`reactive()` 包对象。
- **computed**：派生状态，依赖变化自动重算并缓存。
- **watch / watchEffect**：监听数据变化执行副作用（请求、同步）。

```vue
<script setup lang="ts">
import { ref, computed } from 'vue'
const count = ref(0)
const double = computed(() => count.value * 2)
</script>
<template>
  <button @click="count++">{{ count }} ×2 = {{ double }}</button>
</template>
```

## 2. 模板与事件

- 插值 `{{ }}`、v-bind（`:attr`）、v-on（`@click`）、v-model（表单双向绑定）。
- 条件 v-if/v-else-if、循环 v-for（带 :key）、样式绑定 :class/:style。
- 事件修饰符：`.stop` 阻止冒泡、`.prevent` 阻止默认。

## 3. 组件通信

- **props 下传**：父传子，只读。
- **emit 上传**：子触发事件通知父。
- **v-model 自定义**：组件上双向绑定。
- **provide/inject**：跨层级注入，适合主题、配置。
- **Pinia**：全局共享状态，如登录态、用户信息；action 里发请求。

## 4. 路由（Vue Router 4）

- 路由表：path + component + meta（标题、角色守卫标记）。
- 动态路由与参数：`/app/:id`，useRoute 取参。
- **导航守卫**：beforeEach 校验登录态与角色，未登录重定向 /login。
- 懒加载：路由组件动态 import，按需分包，首屏更快。

## 5. 工程化

- **TypeScript**：接口定义 API 响应类型，编译期（vue-tsc）发现类型错误。
- **axios 封装**：拦截器统一加 Bearer token、401 刷新重试、解包 {success,data} 统一错误提示。
- **SSE 流式**：fetch + ReadableStream 逐块读取，不用 EventSource（需要带 Authorization 头）。
- **Vite**：开发热更新，代理 /api → 后端；生产构建产出静态文件。
- **环境变量**：VITE_APP_* 前缀，.env 文件区分 dev/prod。
- **CSS**：全局 styles.css 定义设计 token（颜色、阴影 CSS 变量），暗色模式 html.dark 覆盖。

## 6. 组件库（Element Plus）

- 常用：el-button、el-input、el-dialog、el-form、el-table、el-tabs、el-tag、el-upload。
- 按需引入减少包体积；深色主题引入 theme-chalk/dark css-vars。

## 7. 性能与规范

- v-for 必须 key；大数据列表用虚拟滚动。
- 长列表渲染前先 loading 态；防抖/节流处理高频事件。
- 大数（雪花 ID）用字符串类型，避免 JS 精度丢失。
- Markdown 渲染必须消毒（DOMPurify），防 XSS。
- 组件风格统一：视图文件 + scoped 样式，无散落组件目录时保持既有约定。

## 8. 调试

- Vue DevTools 看组件树与响应式依赖。
- Network 面板定位接口慢/失败；vue-tsc 严格模式跑构建前检查。
- 常见坑：ref 在模板自动解包但脚本里要 .value；响应式丢失（解构 reactive）；异步更新用 nextTick。
