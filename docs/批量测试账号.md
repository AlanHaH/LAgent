# 批量测试账号

该工具仅用于本地开发数据库。它可以批量创建、查看和删除测试账号，跳过邮件验证码流程，但不会修改正式的注册接口。

## 图形化菜单

项目和 Docker 启动后，双击根目录的 `test-accounts.cmd`：

1. 创建一批学生或管理员账号；
2. 查看脚本创建过的账号及所属批次；
3. 删除指定批次；
4. 删除全部测试批次。
5. 重置指定批次的统一登录密码。

创建时输入一次密码，同批次账号共用该密码。密码只在内存中生成 BCrypt 哈希，不会写入脚本、注册表或测试报告。

批次名可以留空，脚本会按当前时间自动生成。密码输入时终端不会显示字符，这是正常现象；需要连续输入两次完全相同的密码。密码不能为空，长度必须为 8～128 个字符。

## 命令行示例

```powershell
# 创建 10 个学生账号；不传 Password 时会安全提示输入
.\scripts\test-accounts.ps1 -Action create -Count 10 -Prefix test_student -Batch goal-test

# 创建 2 个管理员账号
.\scripts\test-accounts.ps1 -Action create -Count 2 -Prefix test_admin -Batch admin-test -Role ADMIN

# 查看账号
.\scripts\test-accounts.ps1 -Action list

# 删除一个批次；需要输入 DELETE 确认
.\scripts\test-accounts.ps1 -Action delete -Batch goal-test

# 删除全部由脚本登记的测试账号
.\scripts\test-accounts.ps1 -Action delete -All

# 重置一个批次的登录密码；不传 Password 时会隐藏输入并要求确认
.\scripts\test-accounts.ps1 -Action reset -Batch goal-test
```

自动化场景中可以增加 `-Force` 跳过删除确认。日常手工操作不建议使用。

## 安全边界

- 只清理 `dev_test_account_registry` 中登记的账号；
- 同时要求账号邮箱为 `@test.local`，并校验用户名、邮箱与登记信息完全一致；
- `admin`、`Alan` 和正常注册账号不会进入测试注册表；
- 删除账号时同步清理画像、目标、项目、计划、任务、学习块、知识库、问答、评估、学习记录、模型运行、审计和登录令牌；
- 该脚本依赖本地 Docker MySQL，不应在生产服务器执行。

如果操作失败，窗口会显示简短原因，并把完整诊断写入 `logs/test-accounts-last-error.log`。
